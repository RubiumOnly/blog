# RubiumOnly 的个人博客

欢迎来到我的个人博客项目！

这个博客脱胎于优秀的开源项目 [XHBlogs](https://github.com/XingHuiSama/XHBlogs)，经过了深度定制和全面私有化。它不仅仅是一个展示内容的平台，更是一个集成了 AI 助手、评论、音乐和动态的多功能空间。

## 🌟 特性

- **全面私有化**：去除了所有演示数据，干净清爽。
- **动态后端配置**：通过 `my-blog-manager` 管理端进行控制。
- **AI 助手集成**：内置基于 Gemini 的全站智能助手（小猫）。
- **Gitalk 评论**：依托 GitHub Issues 的轻量评论系统。
- **网易云音乐挂件**：自定义后台音乐同步。
- **Vercel 部署**：支持一键快速构建与分发。

## 🚀 部署指南

1. **环境准备**：
   - 申请 Gemini API Key
   - 申请和风天气 API Key（可选）
   - 创建 GitHub OAuth App
2. **Vercel 设置**：
   - 将此仓库导入 Vercel
   - 选择 `Next.js` 框架，根目录设定为 `XHBlogs` 或根节点
   - 在 Environment Variables 填入所需的变量
3. **完成部署**：
   - 配置自定义域名（可选）
   - 访问并开启博客之旅！
